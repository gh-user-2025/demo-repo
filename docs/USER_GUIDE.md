## Getting Started

### Logging In

1. Navigate to the application URL
2. Enter your email and password
3. Click "Login"

**Demo Credentials:**
- Admin: admin@example.com / admin123
- Manager: manager@example.com / manager123
- Developer: developer@example.com / dev123

### Registering a New Account

1. Click "Register here" on the login page
2. Fill in your details:
   - Full Name
   - Email
   - Password (minimum 6 characters)
   - Confirm Password
   - Select your role
3. Click "Register"

### Navigation

The sidebar on the left provides quick access to all main sections:
- **Dashboard**: Overview of your projects and tasks
- **Projects**: View and manage all projects
- **Tasks**: View all your tasks
- **Teams**: Manage teams and members
- **Analytics**: View detailed reports and analytics

## Dashboard

The Dashboard provides a quick overview of your work:

### Key Metrics
- **Total Projects**: Number of projects you're involved in
- **Total Tasks**: Number of tasks assigned to you
- **Completed Tasks**: Tasks you've finished
- **Overdue Tasks**: Tasks past their due date

### Visualizations
- **Task Status Distribution**: Pie chart showing tasks by status
- **Project Status**: Bar chart showing active, completed, and on-hold projects

### Recent Tasks
View your most recent tasks with their priority and status.

## Projects

### Viewing Projects

1. Click "Projects" in the sidebar
2. You'll see all projects you have access to
3. Each project card shows:
   - Project name and status
   - Description
   - Progress bar
   - Team size
   - Due date

### Creating a New Project

1. Click the "New Project" button
2. Fill in the project details:
   - **Name**: Project name (required)
   - **Description**: Brief description of the project
   - **Start Date**: When the project begins
   - **End Date**: Project deadline
3. Click "Create Project"

### Viewing Project Details

1. Click on any project card
2. You'll see:
   - Full project information
   - Overall progress
   - List of all tasks
   - Task completion status

### Managing Project Tasks

From the project detail page:

1. Click "New Task" to create a task
2. Fill in task details:
   - **Title**: Task name (required)
   - **Description**: Detailed task description
   - **Priority**: High, Medium, or Low
   - **Status**: To Do, In Progress, or Completed
   - **Assign To**: Select a team member
   - **Due Date**: Task deadline
   - **Estimated Hours**: Time estimate
3. Click "Create Task"

### Updating Task Status

- Click the checkbox next to a task to mark it as complete
- The project progress bar updates automatically

## Tasks

### Viewing Your Tasks

1. Click "Tasks" in the sidebar
2. See all tasks assigned to you or created by you

### Filtering Tasks

Use the filter buttons at the top:
- **All**: Show all tasks
- **Active**: Show incomplete tasks
- **Completed**: Show completed tasks only

### Task Information

Each task displays:
- Task title and description
- Priority badge (High/Medium/Low)
- Project name
- Current status
- Assigned person
- Due date

### Completing Tasks

Click the checkbox next to any task to mark it as complete.

### Task Statistics

At the bottom of the Tasks page, view:
- Total tasks count
- Completed tasks
- In-progress tasks
- To-do tasks
- Priority distribution

## User Roles

### Developer
- Create and manage own tasks
- View assigned projects
- Update task status

### Manager
- All Developer permissions

- Create and manage teams

### Admin
- All Manager permissions

## Best Practices

### Project Management

1. **Set Clear Deadlines**: Always set realistic start and end dates
2. **Break Down Work**: Create smaller, manageable tasks
3. **Regular Updates**: Update task status regularly
4. **Use Descriptions**: Provide clear descriptions for projects and tasks

### Task Management

1. **Set Priorities**: Mark urgent tasks as high priority
2. **Realistic Estimates**: Provide accurate time estimates
3. **Update Status**: Keep task status current
4. **Check Deadlines**: Regularly review upcoming due dates

### Team Collaboration

1. **Assign Clearly**: Assign tasks to specific team members
2. **Balance Workload**: Check team workload in Analytics
3. **Communication**: Use descriptions to communicate requirements
4. **Track Progress**: Monitor project progress regularly

### Using Analytics

1. **Weekly Reviews**: Check analytics weekly for insights
2. **Workload Balance**: Ensure team workload is balanced
3. **Identify Bottlenecks**: Look for overdue or stuck tasks
4. **Track Trends**: Monitor completion rates over time

## Troubleshooting

### Can't Log In
- Verify your email and password are correct
- Try using a demo account to test
- Clear browser cache and cookies

### Don't See a Project
- Check if you're a team member on the project
- Contact the project owner or admin

### Can't Create Project/Task
- Verify you have the appropriate role (Manager or Admin)
- Ensure all required fields are filled

### Page Not Loading
- Refresh the browser
- Check internet connection
- Try a different browser
